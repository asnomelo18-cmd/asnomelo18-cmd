## À propos de moi

Je suis un **jeune développeur passionné**, étudiant en **BTS Informatique et Développement d'Application** à Abidjan, en Côte d'Ivoire. J'apprends en construisant : sites vitrines, boutiques en ligne, applications mobiles et, en ce moment, une application web complète de planification.

Je suis **ouvert aux stages et aux missions** en développement web et mobile.

J'aime les projets concrets, le code propre et les interfaces soignées. Et quand je ne code pas, je regarde des **animés** : ils me donnent souvent l'envie de m'améliorer, un arc à la fois.
