## À propos de moi

Je suis un **jeune développeur passionné**, qui apprend en construisant : sites vitrines, boutiques en ligne, applications mobiles et, en ce moment, une application web complète de planification.

J'aime les projets concrets, le code propre et les interfaces soignées. Et quand je ne code pas, je regarde des **animés** : ils me donnent souvent l'envie de m'améliorer, un arc à la fois.
